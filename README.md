🎵 Music Store SQL Project
📌 Overview
This project analyzes a music store database using SQL queries. It demonstrates skills in joins, aggregations, window functions, and reporting to extract insights such as customer purchase behavior, revenue contribution by product categories, and automated reporting.

⚙️ Features
Queried 10,000+ transaction records using SQL joins, aggregations, and window functions.

Identified top 3 product categories contributing ~65% of total revenue.

Automated reporting with Excel pivot tables, reducing manual analysis time by ~40%.

🛠️ Tech Stack
SQL (Joins, Aggregations, Window Functions)

Excel Pivot Tables for reporting

Dataset: Music Store transactions

🚀 How to Run
Import the dataset into your SQL environment (MySQL/PostgreSQL/SQLite).

Run the queries provided in the scripts/ folder.

Export results to Excel for pivot table reporting.

📊 Insights
Customer purchase behavior trends.

Revenue concentration in key product categories.

Efficiency gains through automation.
